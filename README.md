# The World in One Day — Friday 20 November 2026

This entry is a small program that writes one image summing up the world news of Friday 20 November 2026 to `/output/entry.png`. The poster gathers the day's biggest stories into a single 1024×1024 frame, so a reader can take in the whole day at a glance.

To run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The poster image `entry.png` is an original drawing rendered by `build_poster.py`.
